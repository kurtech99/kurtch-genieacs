📌 PILIHAN 1: VERSI WINDOWS (FOLDER: windows)
==================================================================================
Cocok untuk: Laptop / PC Server Windows 10/11 atau Windows Server.

Langkah Pasang:
1. Buka folder "windows".
2. Download & instal MongoDB Windows (Gunakan link: "1.Mongodb-Download.url").
3. Download & instal NodeJS LTS (Gunakan link: "2.NodeJS-Download.url").
4. Klik kanan pada file "3.Install-ACS.bat" -> Pilih "Run as administrator".
5. Tekan ENTER untuk lokasi default (C:\genieacs-app).
6. Selesai! GenieACS dan Panel NOC otomatis langsung aktif dan berjalan di background.

Akses:
- NOC Web Panel : http://localhost:3300  (atau http://IP_KOMPUTER:3300)
- GenieACS UI   : http://localhost:3000

==================================================================================
Cocok untuk: 
- Server Ubuntu 20.04 / 22.04 / 24.04 LTS & Debian 11/12
- STB Bekas B860H / HG680P (Hemat listrik ~5 Watt, colok LAN dapat IP DHCP MikroTik)
- Proxmox VE (LXC Container Debian 12 / Ubuntu 22.04 baru)
- Cloud VPS (Ubuntu / Debian dengan IP Publik)

Langkah Pasang (Server Baru):
1. Buka folder "LINUX-STB-PROXMOX-VPS".
2. Salin seluruh isi folder tersebut ke server Ubuntu/Linux Anda via WinSCP ke folder "/root/".
3. Buka terminal PuTTY / SSH, ketik:
   cd /root/LINUX-STB-PROXMOX-VPS
   chmod +x install.sh
   bash install.sh
4. Tunggu 3-5 menit. Script otomatis memasang Node.js, MongoDB, GenieACS, 
   Virtual Parameters, Panel Web, dan mendaftarkan auto-start on boot (systemd).

Akses:
- NOC Web Panel : http://IP_SERVER:3300
- GenieACS UI   : http://IP_SERVER:3000
